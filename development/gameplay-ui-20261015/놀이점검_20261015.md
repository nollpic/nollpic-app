# 놀픽 챌린지 v3 놀이 점검 (2026-10-15, Claude)

점검 방법: `놀픽앱챌린지_v3/public` 을 로컬에서 띄우고(운영 Firestore 쓰기 차단 장치를 끼운 상태), 게스트로 2학년(저학년)·5학년(고학년) 아이 프로필을 넣어 직접 플레이.
- 직접 끝까지 해 본 것: 크리스탈 광산(저·고), 마법 회로 1·2단계(저), 반전 마법사 1·2단계(저), 컬러 마법사 1단계(저), 369 암호 1~3단계(저), 비밀 건축 연구소 1단계 일부(저), 비밀의 문 1단계(저), 9칸 위치기억 1단계
- 예전 놀이 18개: 저학년(level=1)·고학년(level=3)으로 열어 오류 여부와 시작 단계 비교 (끝까지 플레이는 안 함)
- 하지 않은 것: 실제 폰(iOS/안드로이드) 확인, 로그인 상태 확인, 새 놀이 고학년 2·3단계 직접 플레이(설정값만 확인)
- 놀이 화면 오류(콘솔 에러): 25개 모두 없음

## 1. 꼭 고쳐야 할 것 (우선순위 순)

1. **새 놀이 7개(1~7일차)를 끝내도 챌린지 도장·포인트가 안 생김**
   - 예전 놀이 18개는 끝나면 앱의 `completeChallengeStep(번호)` 또는 `claimChallengeStepReward(번호)`를 부름 → 지도 도장
   - 새 놀이(`minigames/`)는 이 함수를 부르는 곳이 0곳. 결과는 기기에만 저장(`local-service.js`, storageMode 'device')
   - 결과 화면에도 "이 기기에 놀이 기록 저장 · 포인트 지급 없음", 광산은 "+20P · 체험 보상 · 실제 적립 없음 / 개발용 기록에만 저장했어요"가 그대로 보임
   - 실제 확인: 챌린지 화면 오늘 카드 → 1일차 크리스탈 광산 → 5/5 성공 → 돌아와도 "0/30일", 오늘 카드 그대로, 포인트 200 그대로 (게스트로 확인)
   - 1~7일차가 전부 새 놀이라 무료 체험 첫 주 내내 도장이 안 쌓일 수 있음
2. **크리스탈 광산(1일차)이 학년을 안 읽고 너무 짧음**
   - 시작 화면 라디오 "단계 선택"의 기본값(1단계)만 씀 → 2학년·5학년 모두 3×3 판, "파란 마름모 2개 찾기"를 5구간 똑같이 반복
   - 1단계는 방해 보석이 목표와 색도 모양도 안 겹치게 만들어져서(engine.js `difficulty===1` 필터) 파란색·마름모는 정답뿐 → 찾을 게 없음
   - 5구간 전체가 1초 간격으로 눌러 7초. 화면 예상 시간 120초, 제한 90초와 차이 큼
   - 첫날 첫 놀이라 인상이 제일 중요한 자리
3. **학년 구분이 놀이마다 다름**
   - 예전 놀이: 3단계(초1~2 / 초3~4 / 초5~6), 새 놀이: 2단계(초1~3 저학년 / 초4~6 고학년)
   - 같은 3학년이 예전 놀이에선 중간, 새 놀이에선 저학년
   - 한 번 했던 놀이를 다시 만나면 "심화"(한 단계 위)로 여는 기능은 예전 놀이만 됨(주소 `?level=`). 새 놀이는 `?level=`을 안 읽음
4. **컬러 마법사(4일차) 1단계에 핵심 훈련이 없음**
   - 1단계는 저·고학년 모두 글자와 색이 항상 같음(card-engine.js: `word=stage===1?ink:...`). 직접 해 보니 8문제 모두 "빨간 '빨강'" 같은 일치 문제
   - 색과 글자가 다른(스트룹) 문제는 2단계부터, 규칙 바뀜은 3단계부터 → 1단계만 하고 끝내면 충동조절 훈련이 0

## 2. 놀이별 메모

공통
- 시작 화면 "예상 시간"이 7개 모두 "—", 광산은 가운데 큰 상자가 비어 있음
- 시작 화면 "GAME 번호"가 지도 순서와 다름 (마법 회로 2일차인데 GAME 03, 반전 마법사 3일차인데 GAME 02, 컬러 마법사 GAME 22, 문 GAME 25)
- 1~7일차는 오늘 카드가 1장(1일차만 2장) → 8일차부터의 "둘 중 고르기"와 다름
- 1단계가 끝나면 "2단계 도전하기"가 나오지만, 아이가 1단계만 하고 나가도 되는 구조라 하루 놀이 시간이 30초~1분으로 끝날 수 있음 → 하루에 몇 단계를 해야 그날 칸이 끝나는지 정하기

### 예전 놀이 18개 (8일차부터 추천)
- 25개 모두 오류 없이 열림
- 학년별 시작 단계가 잘 바뀌는 놀이: 기억 공방(스시→햄버거), 숫자더하기(쉬움→어려움), 모양기억(레벨1→3), 색 조각(이지 4개→하드 9개), 9칸(X 비우기→빨강·파랑 컵), 색깔 블록(더하기→위치 찾기), 색깔대로 말해요(같은 색 연습 3문제→섞어서 10문제), 거꾸로 369(한 자리→헷갈리는 숫자), 생선 굽기(난이도1→3), 숫자 숨바꼭질(16개→28개), 컬러 비눗방울(2색 15개→4색 20개), 재료 조립(2개→3개+방해), 길 잇기(6×6 3쌍→8×8 6쌍), 숫자로 찾기(4×4→6×6)
- 문제
  - **꼬인 길 작전**: 고학년은 7단계부터여야 하는데 화면은 "1/30단계"와 같은 판(점 3개) 그대로. 내부 값(stage=7)만 바뀌고 판은 안 바뀜
  - **색 조각 맞추기**: 중학년(3~4학년)도 저학년과 같은 이지 모드
  - **손가락 순서·탁구·블록 합치기**: 학년 구분 없음
  - **색깔대로 말해요**: 저학년은 3문제뿐이라 아주 짧음. 마이크(음성 인식)가 필요하고 "맞게 말했어요"를 스스로 누를 수 있음. 아이폰 사파리·카톡 인앱 브라우저에서 음성 인식이 안 될 수 있음
  - **9칸 위치기억**: 배송 종이컵으로 하고 엄마가 확인하는 놀이(사용자 확인). 그런데 `challenge-games.js` 6번에 `kit`(준비물)가 비어 있어 1일차(교구 받기 전)에도 두 번째 카드로 추천됨 → `kit: '종이컵 8개'` 같은 값 필요. 버튼 "완성했어요" → "엄마가 확인했어요"처럼. 도장은 3개 난이도를 모두 끝내야(finishGame) 찍힘
  - **기억 공방·탁구 랠리**: "포인트 받기"를 눌러야 도장 (나머지는 자동)

## 3. 재미 요소 의견
- 좋은 점: 새 놀이는 그림·배경(광산·마법탑)·별 3개·콤보·단계 열기 구조가 있어 "게임" 느낌이 확실함. 369 암호·반전 마법사 2단계 이후는 규칙이 바뀌는 순간의 긴장감이 있어 재밌음
- 아쉬운 점: 1단계가 대부분 너무 쉽고 짧아서 "더 하고 싶다"보다 "벌써 끝?"이 먼저 옴. 첫 주(1~7일차)가 전부 1단계 위주라 첫인상이 약함
- 제안
  1. 하루 놀이 = 1단계가 아니라 "2단계까지" 또는 "3분 이상"처럼 기준을 정하기
  2. 1단계에도 핵심 규칙을 1~2문제는 넣기 (컬러 마법사 불일치, 반전 마법사 규칙 전환, 광산 비슷한 방해 보석)
  3. 결과 화면에 실제 포인트·도장을 보여 주기 (지금은 "지급 없음"이라 보상감 0)
  4. 힌트는 정답 대신 "다시 한 번 보여 주기"로, 횟수 제한

## 4. 크리스탈 광산 개편 (2026-10-15 적용, 로컬 v3만 · 배포 안 함)
바꾸기 전 파일: `_backup/crystal-mine-20261015/` (game-intro-config.js는 ATT-001 항목의 difficultyLabels·verifiedDuration만 바뀜)
- 보석 그림(graphics.js): 깎인 면·반짝임이 있는 크리스탈 6모양(마름모·육각·팔각·물방울·하트·별) × 6색(파랑·보라·초록·빨강·분홍·노랑), 금 간 보석·거꾸로 선 보석
- 학년 자동 반영: 아이 학년 4학년 이상 = 고학년, 그 밖 = 저학년 (시작 화면 "단계 선택"에서 바꿀 수 있음: 1 저학년 · 2 고학년)
- 저학년(config.bands.lower): 8구간, 제한 150초. 3×3 → 4×4, 구간마다 목표 보석이 바뀌고(앞 구간과 색·모양 모두 다르게) 같은 색/같은 모양 보석이 점점 섞임. 5·8구간은 두 종류 함께 찾기
- 고학년(config.bands.upper): 90초 타임어택, 목표 10구간. 1 비슷한 깎임(육각↔팔각) · 2 비슷한 색(파랑↔보라, 빨강↔분홍) · 3 금 간 보석은 빼고 · 4 거꾸로 된 건 빼고 · 5 찾는 중에 목표가 바뀜, 6구간부터 이 유형들이 섞여 계속. 결과에 "N구간까지 탐험!" + 최고 기록/신기록(기기 저장 `nollpic:crystal-best:<아이>:upper`), 목표 달성 시 보물상자 열리고 계속
- 틀렸을 때 이유별 안내: "금 간 보석은 빼요!" · "거꾸로 된 보석이에요!" · "목표가 바뀌었어요!"
- 남은 시간: 큰 숫자 알약 + 줄어드는 막대, 20초↓ 주황 · 10초↓ 빨강(두근)
- 결과 카드·상세 기록 글씨가 흰 바탕에 흰색이던 것 → 진한 색
- 확인: 엔진 각 학년 1,500~3,000판 생성·완주 오류 0. 정답만 1.8초 간격 시뮬레이션 저학년 8구간 약 50초, 고학년 90초 11구간. 화면에서 저·고학년 진행, 목표 바뀜, 결과·신기록 확인
- 남은 일: 여전히 챌린지 도장·포인트 연결 없음(1번 문제). 다른 놀이가 쓰는 `randomFrom`은 그대로. `verification/`의 자동 테스트 중 광산 예전 규칙(1~3단계, 별 표시)을 확인하던 것은 다시 맞춰야 함
- 2차 (사용자: "거의 똑같은 레벨로 이어지는 느낌") — 갈수록 확실히 어렵게
  - 저학년 8구간: 3×3(2·2·3개) → 4×4(3개, 5구간 두 가지 함께, 6구간 새 규칙 금 간 보석) → 5×5(7구간 4개, 8구간 두 가지 3개씩=6개)
  - 고학년: 1~5 규칙 배우기(헷갈림 1가지) → 6~10 규칙 겹치기(금+비슷한 색, 거꾸로+비슷한 색, 목표 바뀜+비슷한 색) → 11~ 깊은 광산 6×6, 찾기 4~6개, 헷갈림 3가지 (loop 5종 반복)
  - 알림: 새 규칙이 처음 나올 때 "새 규칙! …", 판이 커질 때 "광산이 더 넓어졌어요!" / "깊은 광산 도착!", 10구간 달성 시 "목표 10구간 달성! 보물상자가 열렸어요 · 이제 깊은 광산으로!", 열린 상자 크게 반짝
  - 시뮬레이션(정답만, 보석당 2.2초): 고학년 90초 약 10구간 → 6×6은 잘하는 아이만 도달. 1,500~2,000판 생성 오류 0
- 틀렸을 때 "땡!" 팝업: 게임판 가운데에 빨간 테두리 카드 "땡!" + 이유(예: 금 간 보석은 빼요!)가 0.7초 톡 튀어나왔다 사라짐(화면을 막지 않아 바로 다음 보석을 누를 수 있음), 틀린 칸 흔들림. 움직임 줄이기 설정이면 제자리에서 나타났다 사라짐
- 틀린 이유 보여 주기 조정 (사용자: 0.7초는 읽기 어렵고, 느리면 안 됨): "땡!" 팝업은 0.7초 그대로, 처음 보는 이유일 때만 1.4초 + 이유 글씨. 이유는 목표 카드 안 빨간 알약으로 다음 정답까지(최대 3초) 남김. 아래 문구 중복은 뺌
