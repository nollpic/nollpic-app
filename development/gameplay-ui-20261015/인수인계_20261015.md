## 3. 배포·업로드 방법 (이 PC 기준, 2026-10-15)
- **Firebase**: v3 폴더에서 `firebase deploy --only hosting --project nollpic --non-interactive` (전역 firebase CLI, monojjin@gmail.com 로그인). firebase.json site = nollpic-challenge
  - 올리기 전 `public/service-worker.js` 첫 줄 CACHE_NAME을 새 이름으로 (지금 `nollpic-v61-crystal-hearts-20261015`)
  - 올린 뒤 `curl https://nollpic-challenge.web.app/<파일>`로 로컬과 같은지 확인
- **GitHub**: 기본 계정 monojjin-tech는 `nollpic/nollpic-app`에 push 권한 없음(403). gh에 저장된 **nollpic** 계정으로:
  `gh auth switch --user nollpic` → `git -c credential.helper= -c "credential.helper=!gh auth git-credential" push origin codex/gameplay-ui-20261015` → `gh auth switch --user monojjin-tech`
  - 줄바꿈(CRLF/LF) 때문에 통째 복사하면 전 파일이 바뀐 것처럼 보임 → `diff --strip-trailing-cr`로 실제 바뀐 파일만 골라 복사
- **배포 전 꼭**: 다른 도구(Codex 등)가 v3를 같이 고치고 있었음(10/15 game-intro.js, 광산 결과 문구). 배포 전에 GitHub판·실제 사이트와 로컬을 비교해서 모르는 변경이 있으면 사용자에게 먼저 확인
